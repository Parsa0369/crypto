# Security policy

- Run the dashboard only on your own computer. It binds to 127.0.0.1 by default.
- Never add API secrets, passwords, wallet seed phrases, or exchange credentials to this repository.
- The application uses public market-data endpoints and does not place trades.
- Do not expose Flask's development server to the internet.
- Report suspected vulnerabilities privately to the repository maintainer rather than posting secrets or exploit details in a public issue.
